# Tarno OS Roadmap

**The project has pivoted.** Tarno OS is now **THOS — a clean-slate hybrid kernel** that
runs native ELF/POSIX and native PE/Win32 programs side by side on one target machine,
with no Linux fork and no virtualization.

- Architecture: [`docs/thos/architecture.md`](docs/thos/architecture.md)

- Honest cost / blocker analysis: [`docs/thos/feasibility.md`](docs/thos/feasibility.md)
- Licensing: [`docs/thos/licensing.md`](docs/thos/licensing.md)
- Target hardware: [`docs/thos/hw-target.md`](docs/thos/hw-target.md)
