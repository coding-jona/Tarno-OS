# Tarno OS

Tarno OS ist ein extrem gestripptes, Linux-basiertes System (Buildroot oder Alpine), das für Low-RAM-Betrieb, minimalen Gaming-Overhead und einen eigenen `tarnod`-Sicherheitsdaemon optimiert ist — ohne den Aufwand eines eigenen Kernels.

Den detaillierten Umsetzungsplan findest du in [ROADMAP.md](ROADMAP.md).
